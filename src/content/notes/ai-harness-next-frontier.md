11月2日晚上10点，DeepSeek 官方账号发了一条动态，标题只有一句英文：Your Harness. You Define It.

配的是一段5分24秒的录屏。

屏幕那头，用户只说了一句话："帮我做一个番茄钟插件。"智能体先加载插件开发技能，读取规范文档，检查当前运行环境里有哪些插槽可用，然后写下配置文件，写下一个638行的前端脚本，调用安装工具把它挂上去，最后自己用命令行跑了一遍，确认计时器真的在走秒。

全程没有人工写一行代码。

很多人把这条新闻当成"又一个AI编程工具发布"。我看完官方架构文档后，判断完全不一样。

这件事真正的信号是：**AI竞争的下半场，正在从模型层，转移到 Harness 层。**

而 Harness 这个词，大部分人还没搞懂。

## 一、先把"马具"这个词讲清楚

Harness，英文原意是马具——套在马身上，让人能驾驭马的那整套缰绳、鞍具和嚼子。

在大模型行业，它指的不是模型，而是模型外面那一整套运行环境：工具怎么调用、权限怎么控制、会话怎么记忆、任务怎么一轮轮推进。

DeepSeek 官方给了一个极简公式：

**Agent = Model + Harness。**

模型负责想，Harness 负责做。模型是马，Harness 是马具。

这个比喻很准。一匹再好的马，没有缰绳你骑不上去；一个再强的模型，没有 Harness 它只是个会聊天的输入框。

同样是 DeepSeek 的模型，套上 Harness，它能读你的代码库、跑终端命令、搜网页、连续工作几小时、把任务拆给子智能体；不套 Harness，它只能给你回一段文字。

所以行业里真正的产品分水岭，从来不是"谁家模型分高两分"，而是"谁家的马具更合手"。

DeepSeek Harness 的时间线值得摆出来看：

8月13日，v0.1 开发者预览版开源，MIT 协议，同一天 DeepSeek-V4-Pro 正式商用。

10月2日，macOS 和 Windows 桌面版打包发布。

10月17日，V4.1-Flash-1017 专门针对 Harness 做了优化，官方提示用户升级到 v0.2.1 以上。

11月2日，Creator Mode 上线。

三个月，从一个开源预览版，走到"一句话造插件"。

还有一点容易被忽略：它不被设计成"DeepSeek 版 Claude Code"。它甚至能把本地装着的 Claude Code、Codex 当成子智能体调用——不是替代它们，是骑在它们上面。

这就是"底座"的思路。底座不跟应用抢生意，底座只负责让所有应用长在自己身上。

## 二、为什么敢白送马具

这里有个商业问题，很值得琢磨。

一家以模型能力立身的公司，为什么要以 MIT 协议把一套花了大半年打磨的框架免费开源，还允许商用？

答案藏在同一天的动作里。

开源 Harness 的 8 月 13 日，DeepSeek 同步上调了 API 价格，V4 Flash 和 V4 Pro 开始走高峰与低谷分时计费。

这两件事放在一起，商业逻辑就清楚了：**免费编排，付费推理。**

马具白送，马按里程收费。

框架免费，装的人就多；装的人多，跑任务消耗的 token 就多；token 消耗多，模型收入就涨。用户省下了授权费，DeepSeek 拿到了推理量，双赢。

对比一下就更明显。Claude Code 的逻辑是订阅制，Pro 每月20美元起，Max 100美元，重度用户还要加钱，框架和模型绑在一起卖。DeepSeek 把这层绑带剪断了：框架开源，模型随便换，接 Anthropic、接 OpenAI、接任何兼容网关都行，你甚至可以把 Claude 的模型接到 dsh 里跑。

短期看是让利，长期看是抢生态位。

这招在中国互联网史上出现过很多次：先把底座免费，让所有人在上面长东西，等生态形成了，收底座之上的钱。

区别在于，这一次的底座是"智能体的运行方式"。

谁定义了智能体怎么跑，谁就定义了未来几年 AI 应用长什么样。

## 三、一切皆插件：从iPhone到安卓

DeepSeek Harness 最核心的设计，官方只用一句话写完了：**Everything is a plugin，一切皆插件。**

这不是营销话术，是字面意思。

在它的架构里，模型适配器是插件，工具注册表是插件，会话日志是插件，沙箱是插件，网页界面是插件，连那个驱动整个智能体运转的主循环——agent loop 本身——也是插件。

没有"必须改源码"的特权内核。想换掉任何一部分，改一行配置。

支撑这一切的，是一个叫 Cordis 的插件元框架。名字取自拉丁语"心脏"的属格，来路很有意思：它不是 DeepSeek 从零写的，而是从 QQ 机器人生态里长出来的，作者是 Koishi 框架的开发者 Shigma。2022 年上 npm，2024 年重构出 Cordis 4，引入基于 fiber 的生命周期体系。后来 DeepSeek 把它内嵌进 dsh，做了十几处本地改造，还和北京大学合著了一篇88页的论文，把"安全地动态装卸组件"从开发者要守的纪律，变成了数学上可以证明的定理。

论文里有个关键结论，我读到时愣了一下：所有对运行环境的变更，最终都归结为同一个原语。提供服务、挂载插件、注册监听器，全是它的特例。所以"任何操作都自动可追踪、可恢复"不是一句口号，而是结构上的必然。

落到工程上，是三层。

**第一层，插件树。** 一个跑起来的 dsh，本质是一棵按顺序拼出来的树。配置模板、组合包、覆盖层，一层层叠上去，上层覆盖下层。想改默认行为，在自己的覆盖层里按 id 写一行就行。

**第二层，接缝。** 每一项能力都是"定义 + 提供方 + 使用方"三件套。以终端为例：定义只声明接口，几乎不变；提供方可以换成本地 bash、沙箱 bash、PowerShell、云端执行环境；使用方完全不关心背后是谁。换一个提供方，改一行配置，其他全不动。

这就是"换一个插头，改变整个产品"。

**第三层，连界面都是插件。** 官方有几十个界面包，浏览器里跑着独立的客户端运行时，所谓"双半插件"：一半跑在服务端管逻辑，一半跑在网页里管界面，通过远程调用通信。

最能说明问题的是它自带的一套"自指工具"——智能体可以用几个工具检查自己正在运行的框架：哪些服务在跑、每个组件什么状态、注册了哪些工具；可以现场定义一个小插件；可以把它放进沙箱跑起来；用完再卸掉。全程不改配置文件、不装依赖、不重启进程。

一个能检查自己、修改自己、卸载自己的系统。

打个比方就清楚了。

Claude Code 更像 iPhone：精心打磨的封闭单体，性能可控、体验一致，但社区碰不到核心，生态上限由官方决定。

DeepSeek Harness 更像安卓：一块开放底板，模型、工具、策略、界面全部即插即拔。拔掉一个插件，它注册过的一切自动清除，不留残留。

所以有人叫它"Agent 时代的安卓"。

效果已经显现：社区插件市场上，目前挂着的插件超过一万八千个。

而"一切皆插件"还带来一个副产品，我认为价值被严重低估了——**会话日志的铁律：模型可见即已记录。**

它的会话日志是一份只追加的事件流，所有抵达模型请求的内容都必须能从日志里还原。恢复、分叉、回放、审查，全部从这一条流派生。

好处很实在：调试一个跑了三小时的长任务，你可以从任意节点拉一个分支，改提示词、改权限，从失败的地方继续跑，不用从头再来。这对做工程的人来说，是能救命的功能。

## 四、会说话，就会造工具

回到开头那个番茄钟。

以前让 AI 写工具，流程是这样的：它生成一段代码，你自己建项目、装依赖、跑起来、修bug。代码是代码，你的工作环境是你的工作环境，两回事。

Creator Mode 做的事，是让智能体直接参与自己运行环境的扩展——它现场写插件、现场安装、现场验证，功能直接长在了框架上。

官方公布了七个演示场景，我挑几个说说：

一个3D画廊，把埃菲尔铁塔、长城、紫禁城做成可旋转的立体模型塞进侧边栏；

一个 Transformer 内部计算的交互式演示，用游戏的方式讲清楚注意力机制怎么运作；

一个带时间轴的视频剪辑台，深色界面，能上传素材、剪切拼接、导出成品，还能在对话框里用自然语言下指令剪片子；

一个论文阅读器，完整保留原始排版，选中文字就能划线、批注、提问；

一个会话成本看板，读你自己的真实对话数据，算 token 消耗、预估花费、CPU 占用。

注意，这些不是玩具网页，是能接进现有体系的真插件。

这件事的意义，值得单独说透。

过去二十年，软件的能力边界由谁定义？由开发团队。用户有需求，提给产品经理，排期、开发、上线，三个月起步。你等不等？等不了也得等。

Creator Mode 给出了另一种可能：**产品的边界，开始由用户的一句话定义。**

你缺什么功能，描述出来，AI 现场造。造得不好，再描述，它再改。软件不再是一个成品，而是一块可以随需求生长的活物。

对开发者的冲击也很直接。过去"写插件"是专业门槛，现在门槛变成了"能不能把需求说清楚"。会表达的人，突然获得了造工具的能力。

当然要泼一盆冷水：官方自己在提示词合集里承认，部分演示插件经过多轮对话调整，一条提示词未必能复现视频里的最终效果。

这是降低了门槛，不是消灭了门槛。

但方向已经很清楚了。智能体的竞争，正在从"让模型更好地使用工具"，转向"让模型帮你创造工具"。

前者是优化，后者是换代。

## 五、冷水要泼够：四个必须清醒的问题

我做了多年测试，对新框架的第一反应永远是：哪里会塌。

DeepSeek Harness 至少四个坑，用之前必须知道。

**第一，安全是真空期。**

官方安全说明写得相当诚实：实验性开发者预览软件，没经过安全审计。它能执行模型生成的代码和命令、加载第三方插件、访问网络、进程、凭据和文件。沙箱和审批能降低风险，但不能保证隔离。

Creator Mode 这块尤其危险。插件装好之后，后台代码跑在主程序进程里，不受工作区沙箱限制。官方甚至规定，"列出插件"这种操作都需要单独授权，批准一次也不会顺带提升整个会话的权限。

说白了：插件在门内，远程服务在门外。装一个插件的信任要求，比接一个远程接口高得多。

让 AI 给自己加功能，爽是真的爽，风险也是真的高。审批弹窗那一下，别随手点。

**第二，成本不是零。**

框架免费，token 不免费。

有测评做过实测：一个"回个PONG"级别的空任务，第一次请求就消耗了13467个输入 token。因为系统提示词、工具描述、注入的仓库规则、技能摘要，全都得随行。

马具很重。每跑一步，你都在为这套马具付推理费。

再看性能对比。11月初有机构用同一个模型、同一批代码库做了一组测试：在两个代码库埋入105个bug，看谁能修出来。DeepSeek Harness 平均修出42.7个，Claude Code 修出39.1个——略胜，但统计检验显示这个差异并不显著；成本上，单次任务1.84美元对1.01美元，反而更贵。

所以别信"开源框架吊打商业产品"的叙事。Harness 影响表现和成本，但任务最终做得好不好，还是看接进来的模型。

**第三，体积和平台有短板。**

有评测统计，macOS 上一次 npm 安装拉了531个包、306MB。桌面版目前只覆盖 macOS 和 Windows，Linux 用户还得走命令行安装。评论区里追问 Linux 的声音一直不少。

**第四，接口在剧烈变动。**

官方明说会有破坏兼容性的变更。今天写的插件，明天可能要返工。生产环境别裸奔，锁版本、写测试、盯更新。

顺带一句：概念门槛不低。Cordis、接缝、插件树、waterfall 这些词，官方文档默认你先懂插件框架。新手进来，得先消化一阵。

## 总结

回到那个公式：Agent = Model + Harness。

过去两年，所有公司都在卷等号左边，比参数、比跑分、比价格战。分数差两分，能开一场发布会。

DeepSeek Harness 把视线拉到了等号右边，并且用"一切皆插件"加"一句话造插件"，回答了两个更根本的问题：框架应该多开放，以及定制的门槛应该多低。

一句话概括我的判断：**模型的竞争，决定AI能想多好；Harness 的竞争，决定AI能做多好。而后者的胜负手，是开放。**

给三条行动建议。

给开发者：值得现在就上手。登录送6元赠金，两条命令装好，把它当成观察 Agent 框架演进的最佳样本——因为它的源码是摊开的。但生产环境再等等，至少等版本稳定。

给企业决策者：认真看"用户定义产品边界"这个趋势。今天是一个番茄钟，明天可能就是员工自己搭的工作流。提前想清楚：你的软件，要不要也长出这种能力？如果长不出来，用户会用脚投票。

给所有人：记住那个审批弹窗。工具越顺手，越要问一句——这段代码是谁写的，它拿到了什么权限。

马具越先进，缰绳越要攥在自己手里。
